# Bellingcat Challenge : Ship Happens
> **Catégorie :** Background Check

## 📋 Présentation
* **Source** : [Bellingcat](https://challenge.bellingcat.com)
* **Catégorie** :Background Check
* **Challenge** : Ship Happens
* **Objectif** : Indentifier le nom d'un navire.
